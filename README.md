# stanford-cs146s-learning

A structured learning repository for preparing and progressing toward **Stanford CS146S: The Modern Software Developer**.

## Learning objectives

- Build strong prerequisites across algorithms, systems, and AI/ML foundations.
- Practice implementation-heavy software engineering habits.
- Consolidate notes, exercises, and projects in one maintainable workspace.

## CS146S preparation pathway

This repository tracks a phased pathway:

1. **Phase 0**: Programming Foundations *(skipped)*
2. **Phase 1**: CS161 — Design and Analysis of Algorithms *(current)*
3. **Phase 2**: CS111 — Operating Systems Principles *(planned)*
4. **Phase 3**: CS221 / CS229 — AI and ML *(optional / recommended)*
5. **Phase 4**: CS146S — The Modern Software Developer *(planned)*

## Learning workflow

1. Pick a topic in a course `syllabus.md`.
2. Capture notes using [`templates/lecture-note.md`](./templates/lecture-note.md).
3. Complete exercises and implementations in the course folders.
4. Update each course `progress.md` and commit changes incrementally.
5. Run `git status` before each commit to ensure focused changes.
