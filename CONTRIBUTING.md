# Contributing

This repository is primarily for a self-directed learning workflow. Contributions should preserve clarity, traceability, and course separation.

## Contribution guidelines

1. Keep changes scoped to one course or one template whenever possible.
2. Use the provided templates in `templates/` for consistency.
3. Update the relevant `progress.md` whenever adding notes, exercises, implementations, or projects.
4. Prefer small, focused commits with descriptive messages.
5. Avoid adding generated artifacts or local environment files.

## Suggested commit style

- `docs(cs161): add note on graph algorithms`
- `feat(cs111): add synchronization exercise solution`
- `chore(templates): refine weekly review template`

## Pull requests

- Use `.github/pull_request_template.md`.
- Explain what learning artifacts were added and which progress trackers were updated.
